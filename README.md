# Modelo de Mander (1988)

Aplicación interactiva desarrollada en Streamlit para el análisis del comportamiento esfuerzo-deformación del concreto confinado y no confinado, basada en el modelo de Mander et al. (1988).

La herramienta permite evaluar columnas circulares (con espiral o estribos) y rectangulares, incorporando el efecto del confinamiento mediante acero transversal, así como la influencia de la tasa de deformación (efectos dinámicos).

## Características principales

- Generación de curvas esfuerzo-deformación para:
  - Concreto no confinado
  - Concreto confinado (estático)
  - Concreto confinado (dinámico)
- Evaluación de cuantía de acero transversal (ρs)
- Cálculo de ductilidad (μ)
- Interfaz interactiva para exploración de parámetros

## Aplicación

Herramienta útil para análisis estructural, diseño sísmico y fines académicos, especialmente en el estudio del comportamiento no lineal del concreto confinado.
